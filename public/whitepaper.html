The Gambia Macro Debt Monitor (GMDM)

Author: Bubacarr M Jallow
Role: Independent Researcher, Theoretical Mathematics
Status: Verifiable Data Architecture

1. Abstract

In theoretical mathematics, a system can only be understood if its variables are observable. In the context of sovereign macroeconomics, the observable variables are the yields, tenors, and accepted amounts of government securities.

Currently, accessing the raw auction data of the Central Bank of The Gambia (CBG) requires manual extraction from interactive web portals. This introduces friction into the data pipeline, hindering independent mathematical analysis.

The Gambia Macro Debt Monitor (GMDM) is a serverless, automated data aggregation engine designed to resolve this friction. It functions strictly as a mirror: it extracts raw numbers from the CBG's official website, timestamps them for validation, and visualizes the resulting short-end yield curves and T-Bill/Sukuk spreads.

The GMDM introduces zero projections, zero estimations, and zero hypotheses. Every data point displayed on the dashboard is a direct mathematical fact, sourced from the official record, and publicly available for independent verification. This paper serves as the documentation for the architecture, the mathematical methodology of the curves, and an invitation to the academic community to utilize this verified dataset for further theoretical and empirical research.

2. The Thesis: The Mathematics of Transparency

Financial systems are often obscured by narrative. However, at a fundamental level, the borrowing of a nation is a sequence of discrete mathematical operations. Let the state of the system be defined by three variables:

T = Tenor (Time in Days)
Y = Yield (Cost of Capital %)
A = Amount Accepted (Volume in Dalasi)

These three variables dictate the liquidity and debt servicing capacity of the state. When this data is locked behind web firewalls or buried in PDF documents, it cannot be modeled.

The thesis of the GMDM is that sovereign debt data should be treated as a continuous, machine-readable function. By building an automated edge-computing pipeline, we transform discrete, static web pages into a structured, time-series database.

This is not a platform for financial advice or political commentary. It is a mathematical instrument. It provides the raw coordinates required to analyze the curvature of The Gambia's debt profile. Any researcher, mathematician, or economist can take the raw JSON data produced by this API and independently verify it against the official records.

3. Methodology: The Verifiable Pipeline

To ensure absolute mathematical integrity, the GMDM architecture is built on three strict rules:

1. Direct Rendering (The Extraction): The system does not rely on third-party data aggregators. It utilizes serverless browser rendering to interface directly with the Central Bank's official website, extracting the exact figures published in their official auction tables.

2. Deterministic Parsing (The Computation): Once the raw structure is retrieved, a deterministic Regular Expression algorithm isolates the exact yields and accepted amounts. There is no "fuzzy" AI or estimation. The string "3.64" is mathematically mapped to the 91-Day T-Bill variable.

3. Immutable Timestamping (The Validation): Every data point is saved to a secure database with a precise validated_date. This creates a permanent historical ledger. If a researcher queries the GMDM API on a specific date, the returned dataset is cryptographically tied to the exact CBG publication it was sourced from.

Mathematical Methodology: The Liquidity Index

To provide a verifiable metric of internal market liquidity, the GMDM extracts the raw volume variables from the CBG auction tables: the Amount Floated (the total volume offered by the Central Bank) and the Amount Applied (the total volume bid by the market).

We calculate the Liquidity Ratio (Lr) using the following formula:

Lr = (Amount Applied / Amount Floated) × 100

This ratio provides a mathematical snapshot of the Dalasi's internal liquidity:

  • Lr > 100% (Oversubscription): The market applied for more capital than was offered. This indicates high liquidity in the banking system and strong demand for sovereign paper. It is visually represented in green on the dashboard.
  • Lr < 100% (Undersubscription): The market failed to apply for the full amount offered. This indicates a tightening of liquidity or a lack of demand at the specified yield. It is visually represented in red.

4. Open Invitation for Academic Improvement

The GMDM is an open-source instrument. Because the data is structured and entirely factual, it is designed to be improved upon.

Fellow researchers, mathematicians, and economists are invited to:

  • Fork the Architecture: Improve the data parsing algorithms or propose alternative mathematical visualizations.
  • Use the Data: Utilize the GMDM API to run regressions on the crowding-out effect of sovereign debt, analyze the liquidity premium between conventional T-Bills and Sukuk-Al-Salaam, or model the term structure of The Gambian Dalasi.
  • Verify Everything: The raw data is your baseline. Check the numbers against the CBG's official website at any time.

5. API Access for Researchers

The data pipeline is exposed via a public REST API. No authentication is required.

GET /api/v1/auctions/latest

This endpoint returns a JSON array of the latest verified auction data, including the auction_date, security_type, tenor_days, yield_rate, and the validated_date.
